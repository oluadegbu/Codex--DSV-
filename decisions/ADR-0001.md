# ADR-0001: Standard-library shadow core
STATUS: ACCEPTED (implementation choice within Phase 0 authority)

Use Python 3.11+, Decimal arithmetic, pure scoring functions, protocol adapters
and deterministic synthetic fixtures. No external runtime dependencies or secrets
are needed. Read-only RPC transport is injected for tests. This lowers bootstrap
operational complexity and leaves Temporal and DEX integrations behind interfaces.

Tradeoffs: no streaming integration, real trade parser or durable orchestrator
exists yet. This decision does not replace the intended Temporal runtime or
approve live trading. Use SQLite for the next safe replay/checkpoint milestone.
