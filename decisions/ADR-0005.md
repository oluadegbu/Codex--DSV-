# ADR-0005 — Offline MCP Events contract lab

STATUS: ACCEPTED WITHIN REVERSIBLE SHADOW DEVELOPMENT AUTHORITY

Add an isolated synthetic Standard Webhooks/MCP Events contract lab without
changing previously certified Runner, planner, HEG or workflow code. Reuse
BridgeStore transactional audit and add lab-only outbox/receipt tables to isolated
test databases. Public subscription identity/event/expiry binding is immutable;
independent channels retain independent queues. Preserve stable event IDs/body
bytes and fresh signing timestamps across bounded retries. Uncertain claimed
outcomes remain quarantined. No receipt becomes approval or task execution.

This is not an OAuth implementation, authenticated remote endpoint, real provider
adapter or service deployment. Synthetic principal gating and ephemeral in-memory
keys prevent confusion with live human identity. Remote auth/interoperability
requires a separate certificate. Preserve previous certification files/source
hashes and export Phase 8 evidence additively.
