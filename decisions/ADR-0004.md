# ADR-0003 — DMB trusted shadow portfolio extension

STATUS: ACCEPTED WITHIN SHADOW AUTHORITY

Use a dedicated BHB SQLite database extension for portfolio jobs, immutable
routing scope, dependency-aware admission, resource fences and consolidated
Brain reporting. Reuse simulated HEG; ordinary BHB dispatch rejects DMB mode.
Store inspected workstream snapshots and hash-pinned Git bundles so independent
labs can be reproduced without remote accounts or credentials.

Separate verified local plumbing from live certification. Same-UID trusted labs
provide logical workspace separation, not a hostile-code sandbox. Actual DAT/DPM
repositories, independent Codex runtime, remote Brain delivery, Windows identity,
OS confinement, providers and GitHub writes remain explicit blocked gates.
No production integrations, paid requests or service installation are implied.

Retain locks AND reservations on uncertain started execution. Only proven
pre-start unavailability may retry. Recovery neither resets authorization nor
assumes an ordinary human approval reconciles an uncertain execution outcome.
Reports expose bounded recent records plus explicit totals/truncation; durable
mailbox/audit rows remain intact and individual task status is addressable.

This is reversible local engineering under the DMB directive. Material external
activation/isolation decisions are separately recorded in REQUEST-0005 and prior
open requests. Temporal compatibility is a contract, not a deployment claim.
