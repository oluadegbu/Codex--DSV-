# ADR-0002: Durable local shadow command journal
STATUS: ACCEPTED (reversible implementation choice)

Use a dedicated SQLite WAL/FULL journal for local paper runs. Atomically recover,
validate and append commands under BEGIN IMMEDIATE. Idempotency is identity plus
canonical payload; conflicting retries fail closed. Reconstruct state from retained
commands rather than updating an unaudited balance snapshot. Pin schema/policy v1.

Tradeoffs: O(n) recovery, one host and bounded research volume. Hash chaining is
accidental-corruption evidence, not adversarial tamper protection. This choice
does not replace Temporal or select production distributed storage. No new
financial limits, real funds, credentials, signing or execution are introduced.
