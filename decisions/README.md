# Durable decisions

Use ADR-<id>.md for reversible implementation choices within authority.
Use REQUEST-<id>.md for material architecture/strategy guidance. Requests contain
CONTEXT, EVIDENCE, OPTIONS, RECOMMENDATION, IMPACT, BLOCKING: YES/NO and HARD_GATE:
YES/NO. State OPEN/RESOLVED; append supervisor response evidence instead of
silently replacing the request. Open requests grant no permission.
