# ADR-0003: Local BHB/HEG shadow authority
STATUS: ACCEPTED (isolated reversible implementation)

Reuse Python standard library and the preserved DCI checkout. Use a dedicated
SQLite mailbox authority for atomic ingress, state, outbox, heartbeat, audit and
simulated escalation delivery. Brain accepts fixed operations; Runner owns state;
HEG simulation is a separate authority. Synthetic count/result commits are atomic.
External process uncertainty is never automatically retried. Retain the existing
paper journal as a separate database/schema.

Prototype Codex exec read-only and local MCP stdio using supported interfaces.
Do not expose network endpoints, live identities, paid providers or services.
MCP Events is a documented candidate for later authorized result delivery.

Tradeoffs: single-host trusted-process boundaries, no hostile-user authentication,
no guaranteed continuous scheduler, no real providers or live ChatGPT subscription.
Windows implementation is gated because the remote identity is Administrator.
These choices do not alter DAT Temporal Integration or any financial hard gate.
